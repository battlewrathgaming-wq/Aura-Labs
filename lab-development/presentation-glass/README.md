# Presentation Glass Development Shelf

Status: candidate development shelf

This folder stages Presentation Glass as a Lab reusable subject.

It is not a target adapter, runtime contract, source schema, or adoption mandate.


## Product Mirror

`product-mirror/` is reserved for the current clean candidate shape.

Candidate material may later include static starter files, primitive CSS/tokens, display selection references, and docs that are safe to offer.

Do not place target-specific outputs, Sense/Atlas trial results, or active workspace handoffs in `product-mirror/`.

## Development Materials

Use `development-materials/` for:

- glass readiness summaries
- target pressure feedback
- safety/polish findings
- primitive inventory notes
- packaging questions
- promotion-readiness records

Development material explains the candidate. It does not ship as normal runtime input.
