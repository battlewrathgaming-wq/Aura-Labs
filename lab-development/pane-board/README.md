# Pane Board Development Shelf

Status: internal tooling development shelf

This folder stages Pane Board as a Lab-local collaboration/tooling subject.

Pane Board helps the Human and agents discuss spatial layout intent before product UI is built.

It is not product UI, target adapter behavior, runtime dashboard customization, bridge contract, or presentation glass.

Pane Board is the shadow puppet show: the Human and agents move shapes, compare arrangements, and record useful shadows as reference material.

## Tooling Mirror

`product-mirror/` is a neutral placeholder for a possible future externalized tool shape.

Default posture: Pane Board remains Lab-only internal tooling. Do not treat this folder as a product packaging lane unless Human/Overseer explicitly opens that question.

Do not place active board state, session captures, or current sketches in the product mirror.
