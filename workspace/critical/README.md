# Critical Terms And Assets

This folder records Lab-critical terms and assets while they are active coordination objects.

Use these files when work touches presentation language, bridge-fed labels, source/freshness/certainty wording, critical UI modules, fixture meanings, or downstream project interpretation.

Accepted terminology policy:

- `F:\Projects\Docs\Aura-Project-Orchestration\terminology\TerminologyAuthorityRuleset-2026-05-24.md`

Authority:

- Lab owns how bridge-fed information is presented to humans.
- Lab should develop and use its own product-agnostic presentation vocabulary for Lab-owned default copy.
- Lab may improve clarity, hierarchy, labels, and presentation language after the bridge.
- Lab must preserve source-project meaning unless Human override resolves a conflict.
- Lab does not own Atlas or Sense internal terms, emitted bridge terms, schemas, payloads, or project doctrine.
- Shared spelling does not imply shared meaning.

Bridge boundary:

- Project internal language is owned by the project.
- Project -> Bridge language is owned by the emitting project.
- Bridge-facing means project-owned language, labels, states, payloads, or events exposed outside the project for downstream bridge or presentation use.
- Bridge -> Interface language is Lab-owned presentation language, bounded by source fidelity and Human decisions.

Design intent:

- Lab default copy should sound like a portable presentation layer, not Atlas, Sense, Core, or backend diagnostics.
- Prefer readout, basis, state, surface, coverage, gaps, warnings, freshness, and availability language for Lab-owned defaults.
- Avoid source-project/domain words as Lab defaults unless they are source-owned and contextualized.
- Source-fed Atlas or Sense terms may pass through only as source-owned data, with meaning traceable.

Files:

- `critical-assets.md` lists presentation modules, files, views, workflows, or contracts agents should treat carefully.
- `critical-terms.md` lists Lab-owned presentation terms, preserve-exact source terms, and translation cautions.
- `lab-vocabulary-instruction-packets.md` stages candidate M13a/M13b/M13c instruction packets for vocabulary inventory, replacement, and guardrail verification.
- `misc/` is a fallback for important notes that do not yet fit the two main files.
