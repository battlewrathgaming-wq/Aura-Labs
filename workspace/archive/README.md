# Workspace Archive

Inactive workspace records may be copied here when they are useful to preserve but should not remain active beside `workspace/current.md`.

Use this only for useful workflow evidence. Do not archive every small edit by habit.

Durable project truth remains in `docs/` only after the project earns it.

Do not use this archive, `docs/gap/to-do`, or `docs/gap/complete` as active work queues. Active execution belongs in `workspace/current.md`.

Suggested filename:

```txt
YYYY-MM-DD-short-milestone-name.md
```
