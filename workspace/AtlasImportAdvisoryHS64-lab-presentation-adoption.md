## Recommended Atlas Concept Starting Points

### 1. Evidence Stack View

Best for first adoption if Atlas wants immediate readability gain.

Goal:

- make evidence/discovery-adjacent material scannable without collapsing meanings
- show expansion status, basis, provenance, freshness, and unresolved gaps

Key guardrail:

- Discovery refs must not look like Evidence until Atlas-owned expansion has made them Evidence.

### 2. Provenance Drawer

Best if Atlas needs traceability without crowding the main view.

Goal:

- show why an item is present, where it came from, when it was read, and what gaps remain
- keep source/basis detail inspectable but secondary

Key guardrail:

- provenance cannot become generic Lab "source detail" if Atlas uses stronger evidence semantics.

### 3. Watch / Marked Split Panel

Best if current Atlas users confuse attention with active checks.

Goal:

- visually clarify that Marked is attention and Watch is active routine check
- show the relationship without making them interchangeable

Key guardrail:

- no renderer copy should imply Marked and Watch are the same state.

### 4. Evidence Delta View

Best if Atlas wants to show change over time.

Goal:

- show newly expanded, unchanged, unresolved, failed, and removed/cleared items since the last read

Key guardrail:

- must not turn into a generic Lab activity timeline or Sense transient viewport.

### 5. Actor Activity Strip

Best as a secondary polish after Evidence Stack or Provenance Drawer.

Goal:

- compact recent actor activity, label refreshes, expansions, and watches run

Key guardrail:

- activity strip must preserve Atlas durability and source basis.
