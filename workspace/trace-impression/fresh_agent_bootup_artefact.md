## Rerun Discipline

Use the current Project-Local Operational Map as the discussion and replacement baseline, not as first proof source for a new run.

Rerun `\` only when:

- source changed materially
- `workspace/current.md` focus changed
- the map is stale or disputed
- a material source gap was identified
- Human or Overseer asks for refresh
- Human sync needs a current local basis

Do not rerun only because:

- a specialist gave advisory input
- a small wording issue was found
- uncertainty is already marked as not proven
- the existing map can answer the question

## Authority Boundary

Trace Impression maps are orientation aids.

They do not create project authority, Dev authorization, target adoption, source-project meaning, or architecture approval.

The map's authority comes from accuracy of display, not decision power.
