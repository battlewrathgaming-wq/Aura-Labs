# Lab Decision Trail

Status: subject-organized decision pointer layer
Date: 2026-06-18

## Purpose

This folder keeps Lab decision history findable without making `workspace/current.md` or `workspace/overview.md` carry the whole timeline.

It is a routing surface, not project authority.

Use:

```txt
workspace/current.md = what is open now
workspace/overview.md = current orientation cache
workspace/decision-trail/* = where subject decision threads live
docs/product-brief.md = what Lab is
docs/boundaries.md = what Lab owns and does not own
lab-development/* = candidate reusable products and workbench history
future lab-products/* = clean consumable offerings
```

## Subject Funnels

- `trace-impression.md`
- `presentation-glass.md`
- `pane-board.md`
- `cross-cutting.md`

## Use Rule

When a question belongs to a Lab subject:

1. Read `workspace/current.md` first.
2. Read `workspace/overview.md` for current orientation only.
3. Read the matching decision-trail file to recover the subject thread.
4. Read subject development shelves only when proof/history is needed.
5. Return to `workspace/current.md` before proposing action.

Do not add every handshake here. Add decision anchors that help agents recover direction.
