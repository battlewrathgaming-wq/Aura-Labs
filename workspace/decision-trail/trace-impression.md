# Trace Impression Decision Trail

Status: pointer funnel
Subject: source-orientation workflow / map lens

## Current Reading

Trace Impression is a Lab-developed source-orientation workflow.

It helps a project produce source-cited local maps for bounded seams and optional Human orientation frames.

Lab provides the lens. The consuming project owns the trace it produces.

## Settled Decision Anchors

- `\` is local-map mode for project-local seam traces.
- `|` is Human orientation sync.
- Trace Impression commands are factual orientation commands, not fuzzy discussion.
- Fresh source orientation happens before old maps are used for comparison.
- Maps are orientation surfaces, not authority.
- Existing maps are discussion/replacement baselines, not primary proof source for new claims.
- Specialist input should use maps as orientation and still verify important claims against source.
- `Shape:` labels mark unaccepted or future-facing units as review handles only.
- Development evidence stays out of the clean product mirror.
- The current candidate lives under `lab-development/trace-impression/product-mirror/`.
- Future promotion to `lab-products/trace-impression/` requires explicit review.
