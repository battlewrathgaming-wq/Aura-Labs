# Lab Cross-Cutting Decision Trail

Status: pointer funnel
Subject: Lab-wide operating shape

## Current Reading

Lab is a workspace for reusable presentation and tooling products.

Lab's recurring pattern is:

```txt
develop in lab-development
prove with assurance
promote to lab-products only when accepted
offer as consumable utility
return output authority to the consuming project
```

## Current Anchors

- `docs/product-brief.md`
- `docs/boundaries.md`
- `docs/statements/lab-utility-consumable-model.md`
- `workspace/overview.md`
- `workspace/current.md`
- `workspace/overseer.md`

## Settled Decision Anchors

- `workspace/current.md` remains the only active executable packet.
- `workspace/overview.md` should act as a current orientation cache, not the all-time decision ledger.
- Decision threads should move into `workspace/decision-trail/` by subject.
- Reusable products in development belong under `lab-development/<subject>/`.
- Clean accepted offerings will eventually belong under `lab-products/<subject>/`.
- Development material, trials, and proof records must not ship as normal runtime input.
- Lab may explore playfully, but Dev work stays bounded by current packets.
