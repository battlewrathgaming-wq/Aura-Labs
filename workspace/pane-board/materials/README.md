# Pane Board Materials

Local PNG files in this folder may be referenced by Pane Board panes as optional material cues.

Use them as Shape See imagination paint only. They are not product styling, source data, bridge state, target-project adoption, or accepted UI.

Pane material paths must stay relative to `workspace/pane-board/` and begin with `materials/`.

After a material session, classify generated PNGs before handoff:

- reference material: keep it here with a product-agnostic name and a short purpose/boundary note
- disposable material: delete it, along with transient screenshots/captures and smoke-only board dust

Run `npm.cmd run verify:pane-board` and `git status --short` after cleanup.
