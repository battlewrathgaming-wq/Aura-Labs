# Source Numbered Map Handoff

Status: Lab sandpit workflow note
Context: Pane Board / source-project meaning map
Example source: `F:\Projects\AURA-Sense\workspace\UIUXHS18-meaning-geometry-passive-telemetry-lab-prep.md`

## Purpose

This note describes the light handoff from a source-project meaning artifact into Lab Pane Board spatial work.

The handoff lets Lab sketch with slim numbered handles such as `#01`, `#02`, and `#03` while the source project keeps ownership of what those handles mean.

## Handoff Shape

Source project artifact:

- defines the surface
- owns the meaning
- lists source terms and state language
- assigns `#NN` handles to display-facing parts
- explains what each handle must not imply

Lab Pane Board:

- imports the `#NN` handles as spatial placeholders
- arranges, groups, scales, and compares them
- captures screenshots and JSON for review
- records human or agent notes about visual feel
- does not rename, reinterpret, or adopt source meaning

## Light Process

1. Source project writes or updates a meaning-geometry artifact.
2. Source project includes a slim `#NN` surface reference index.
3. Human or Overseer identifies that the artifact is ready for Lab spatial exploration.
4. Lab creates a Pane Board sketch using the `#NN` handles.
5. Agent proposals may rearrange the same handles without changing their meaning.
6. Human reviews the sketch for feel, priority, and spatial relationship.
7. If useful, Lab records the accepted, adapted, parked, or rejected sketch.
8. Source project remains responsible for any adoption or implementation runway.

## What Lab May Do

Lab may:

- place `#NN` handles on the board
- resize and group numbered panes
- test first-read hierarchy
- test density and proximity
- create alternate proposals
- describe visual relationships
- export screenshots and JSON
- say a layout feels clearer, louder, quieter, cramped, or promising

## What Lab Must Not Do

Lab must not:

- treat `#NN` as product copy
- create a new meaning table
- rename source-project terms
- collapse source states into Lab states
- infer hidden meaning from a number
- convert source bindings into visible UI copy
- create a Dev runway from the sketch alone
- claim target-project adoption
- turn the Pane Board sketch into a bridge or renderer contract

## Resting Record

A complete light handoff can rest as:

- the source meaning artifact
- one Pane Board JSON sketch
- one exported screenshot
- a short note saying why the sketch was accepted, adapted, parked, or rejected

That is enough for continuity. A separate ledger or table is not required unless the Human asks for one later.

## Acceptance Signal

This workflow is working when a future agent can open the source artifact, open the Pane Board screenshot/JSON, and understand:

- what each `#NN` points back to
- which project owns the meaning
- what spatial relationship was being tested
- whether the Human liked, adapted, parked, or rejected the arrangement
- that no implementation authority was created by the sketch
