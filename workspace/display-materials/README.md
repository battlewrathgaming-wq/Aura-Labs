## Page Shape

Each page should stay short and repeatable:

- Purpose
- Slots
- States
- Content lanes
- Visual structure
- Interaction/reveal
- Narrow behavior
- Staged material needs
- Verification minimum
- Risks / parked notes
- Examples/screenshots links when they exist
